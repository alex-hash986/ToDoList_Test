# Мои задачи

Адаптивный список дел на HTML5, Tailwind CSS через CDN и Vanilla JavaScript. Сборка и установка пакетов не нужны.

## Запуск

Откройте `index.html` в современном браузере. Для предсказуемого сохранения задач используйте локальный HTTP-сервер. Поведение `localStorage` для адресов `file://` зависит от браузера.

Если установлен Python 3, выполните команду в папке проекта и откройте [http://localhost:8000](http://localhost:8000).

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Для загрузки [Tailwind Play CDN](https://tailwindcss.com/docs/installation/play-cdn) требуется интернет.

## Управление

- Введите текст и нажмите **Добавить** или **Enter**. Пробелы по краям удаляются.
- Используйте чекбокс, чтобы отметить задачу выполненной или снова сделать её активной.
- Нажмите значок карандаша или дважды кликните по тексту задачи. **Enter** сохраняет правки, **Escape** отменяет их.
- Используйте значок корзины для удаления одной задачи. Кнопка **Очистить выполненные** удаляет все завершённые задачи независимо от выбранного фильтра.
- Фильтры меняют видимый список. Счётчик **Осталось** всегда показывает общее число активных задач.

## Файлы

- `index.html` содержит разметку интерфейса, шаблоны строки и редактора, подключение Tailwind CDN.
- `style.css` задаёт фон, состояния кнопок и полей, стиль выполненных задач.
- `app.js` отвечает за состояние, отрисовку, обработку действий и сохранение.

В `localStorage` по ключу `todos_app_data` хранится JSON-массив объектов с полями `id` (строка), `text` (строка) и `completed` (логическое значение). Данные привязаны к браузеру и адресу приложения. При повторном запуске используйте тот же адрес и порт.
